

# 变更监测

## 什么是变更检测

变更检测就是通过检测视图与状态之间的变化，在状态发生了变化后，帮助我们更新视图，这种视图和数据同步的机制就叫做变更检测。

## 变更检测触发时机

如果发生以下事件就会触发检测：
- 任何浏览器事件(click、keydown等)
- 异步操作
  - setTimeout、setInterval
  - ajax请求

## angular如何订阅异步事件执行变更检测的
 zone.js通过`Monkey Patching`(猴子补丁)的方式对浏览器中常见的方法和元素进行拦截，例如setTimeout和HTMLElement.prototype.onclick。

 angular通过zone.js创建了一个自己 的区域并称之为NgZone,Angular应用中所有的异步操作都运行在这个区域中。

 ## 变更检测是如何工作的

 Angular的核心是`组件化`，组件的嵌套会形成一棵组件树。
 angular在生成组件的同时，还会为每一个组件生成一个变更检测器 `changeDector`，用来记录组件的数据变化状态。
 在创建一个angular应用后，angular会同时创建一个`ApplicationRef`的实例，这个实例就是我们当前创建的这个angular应用的实例。ApplicationRef创建的同时会订阅ngZone中的`onMicrotaskEmpty` 事件，在所有微任务完成后调用所有视图的 detectChanges()来执行变更检测。
 每次触发变更检测，都会从组件树的根节点开始从上到下执行每个组件的变更检测。


 ## 变更检测执行顺序

  1. 更新所有子组件绑定的属性
  2. 调用所有子组件生命周期的钩子OnChanges,OnInit,DoCheck,AfterContentInit
  3. 更新当前组件的DOM
  4. 调用子组件的变更检测
  5. 调用所有子组件的生命周期钩子ngAfterViewInit


## 变更检测策略

angular提供了两种变更检测的策略
- Default
- OnPush

### Default策略
默认情况下，angular使用 ChangeDetectionStrategy.Default变更检测策略，每次触发变更检测时，此默认策略都会从上到下检查组件树中的每一个组件。

### OnPush策略
修改组件装饰器的changeDetection来更改变更检测策略
```ts
@Componet({
    selector:'xxx',
    changeDetection: ChangeDetectionStrategy.OnPush
})
```
设置为OnPush策略后，每次触发变更检测后会跳过该组件和该组件的所有子组件的变更检测。
在OnPush策略下，只有以下几种情况会触发组件的变更检测
- 输入值(`@Input`)更改
- 当前组件或子组件之一的DOM绑定事件（click、submit、@HostListener，render2.listen监听的事件并与会触发变更检测，dom.addEventListener监听的dom事件不会触发变更检测）
- 手动触发变更检测
- Observable订阅事件，同时设置AsyncPipe

#### 注意事项

@Input()的值必须是一个新的引用才会触发变更检测。
在OnPush策略下以下操作不会触发变更检测
- setTimeout
- setInterval
- Promise
- this.http.get().subscribe()

手动触发检测：
- detectChanges(): 它会触发当前组件和子组件的变更检测
- markForCheck(): 它不会触发变更检测，但是会把当前OnPush组件和所有父组件为OnPush的组件标记为需要检测的状态，下一个变更检测周期进行检测。
- ApplicationRef.tick(): 根据组件的变更检测策略，触发整个应用的变更检测

使用async管道
内置的AsyncPipe订阅一个observable并返回它发出的最新值。每次发出新值时内部AsyncPipe调用markForCheck

```ts
private _updateLatestValue(async:any,value:Object):{
    if(async === this._obj){
        this._lastValue = value;
        this._ref.markForCheck();
    }
}
```
