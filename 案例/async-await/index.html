状态机实现示例

async/await 的底层实现基于生成器函数(Generator)和状态机(state machine)。编译器将async函数转换为一个生成器函数，并使用状态机来管理其执行流程。

每个await表达式都会导致函数的执行挂起，此时控制权返回给事件循环，当异步操作完成后恢复执行。

async function fetchUserData() {
  // 暂停并等待数据响应
  const response = await fetch('api/user');

  // 暂停并等待数据解析
  const user = await response.json();

  // 暂停并等待用户权限
  const permissions = await fetchPermissions(user.id);

  return { ...user, permissions };
}

底层状态机结构

Babel等编译器将上述代码转换为类似以下结构的状态机实现：

function fetchUserData() {
  return _asyncToGenerator(function* () {
    // 状态0: 开始执行
    let response, user, permissions;

    // 状态1: 发送网络请求
    response = yield fetch('api/user');
    // 状态2: 解析JSON
    user = yield response.json();
    // 状态3: 获取权限
    permissions = yield fetchPermissions(user.id);
    // 状态4: 返回值
    return { ...user, permissions };
  });
}

状态机详细工作流程

async/await 核心机制：状态机原理

async函数被编译成一个状态机，该状态机通过Generator和Promise的协作实现异步流程控制。

主要步骤:

  1. 初始化: async函数被调用时，返回一个Promise并启动生成器
  2. 状态转换: 每个await对应一个状态转换点
  3. 挂起: 当遇到await表达式时，状态机挂起执行并返回控制权
  4. 恢复: 异步操作完成后，状态机恢复执行到下一状态
  5. 错误处理: 通过try-catch块处理异步错误

状态机的核心元素:

  • generator: 生成器函数，管理执行上下文
  • state: 当前执行状态（0:初始状态, 1:await1, 2:await2等）
  • value: 当前yield返回值
  • _next(): 状态机推进函数
  • _throw(): 状态机错误处理函数
